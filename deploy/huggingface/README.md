# Chakranetra — road defect detection to accountable municipal tickets

Live API + operations console. Upload a road photo with a lat/lon and watch it
become a deduplicated, prioritised, SLA-tracked repair ticket.

- `/`              the operations console
- `/docs`          interactive API documentation
- `/api/scan/image`  photo + lat/lon → detection → ticket

Source: https://github.com/VijayabaskarR-06/chakranetra
